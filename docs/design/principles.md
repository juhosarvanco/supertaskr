# Product principles — decisions of record (pre-market-research)

## The four magic principles
1. **The interview is the product.** Facilitation craft, encoded —
   challenge weak answers, never transcribe them. Polish relentlessly;
   keep everything else thin.
2. **Zero-config gradient.** One installed model → everything defaults
   to it. Advanced (multi-model roles) is revealed, never required.
   Magic dies at the first mandatory config.
3. **Inspectable and escapable.** Every artifact is markdown in the
   repo; every automated session is one the user could open by hand.
   If the tool vanishes, the project continues unharmed.
4. **Ceremony scales with stakes.** The default path must feel lighter
   than not using the system, or it gets abandoned by Thursday.

## Standing rules
- Stop designing when ideas outrun beginnings; version numbers are
  earned by friction from real runs, not by good ideas.
- Bootstrap: build the product WITH the method from task one (ADR-001).
  The overhead we feel is data.
