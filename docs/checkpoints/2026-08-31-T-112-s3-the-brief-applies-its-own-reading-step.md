## What landed

Row 3 of the dispatch-brief contract now **applies** the brief's own role
file's reading step instead of printing the adapters' lists beside it.
The contract always said so — *"the adapter is addressed to every seat
and the role file to one, so where they differ the ROLE FILE WINS"* — and
the tool transcribed instead of applying, so **every brief it had ever
emitted told its executor to read `docs/ROADMAP.md`, which
`method/roles/executor.md` step 1 subtracts in as many words, and none
carried the addition that step names.**

The emitted row now shows the adapters' lists unchanged, then what the
role file SUBTRACTS, then what it ADDS, then the applied set — so a
reader can see which document was removed and which was added rather
than being handed a silently-different list.

**THE DERIVATION CARRIES NO DOCUMENT NAME, and this seat verified that at
the merge rather than accepting it.** `readSubtractions` matches the
literal `do NOT read ` and hands the rest of the line to `docsNamed`;
`readAdditions` matches `ADDITION TO THAT SET IS ` and hands its
remainder to `backtickRuns`; `docsNamed` is a shape
(`docs/**.md`), not a name. Neither subtracted nor added document is
spelled anywhere in the tool, so a role file that changes its mind moves
the brief without anyone editing the assembler.

## The integrator review's own finding

**The two arms do not share a vocabulary.** Subtractions are read with
`docsNamed`, which matches only `docs/**.md`; additions are read with
`backtickRuns`, which matches any backticked run. Correct for today's
role files — the subtraction names a `docs/` path and the addition names
`tasks/TASK-FORMAT.md`, which is not one — but **a future role file
subtracting a non-`docs/` document would silently subtract nothing**, in
a tool whose entire subject is that a silent difference between adapter
and role file cost every brief its correctness. Not rework; the card
asked for the two sentences to be applied and they are. Routed to triage
as an observation.

**And the executor disclosed a deviation nobody would have caught**: it
did the ramp-up reading but skipped writing the one-paragraph
confirmation `executor.md` step 1 asks for before touching code. Recorded
rather than waved through — that paragraph exists to surface a misreading
BEFORE the work, so skipping it spends a safety net, and this one going
well is luck rather than evidence.
