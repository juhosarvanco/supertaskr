**ROUTED, NOT TAKEN.** `docs/CONVENTIONS.md` is outside T-133's fence.

## What the command does today, and why it is not right

`executor.md` row 9 asks the brief to carry *"what this project requires
of every handoff, drills included"*, assembled from CONVENTIONS. There is
nothing in that file that says which bullets those are. The command
therefore enumerates by the file's own TYPOGRAPHY: a column-zero bullet
in `## Gotchas` whose opener is an ALL-CAPS phrase of at least two words,
minus the ones row 8 already answered as gates.

**That is a signpost derivation, and this repository has a bullet about
exactly what happens to those.** Measured at `5036958` it returns
fourteen names, and they are the right fourteen — but two of them
(`A CITATION NAMES A SYMBOL, NOT A LINE`, `DECLARING A COMPONENT`) are
techniques rather than handoff disciplines, and one (`A RENDER-PHASE REF
STAMP`) is a code rule. **Over-inclusion is the safe direction** and the
command says so in its own header, for the same reason a gate trigger is
deliberately wider than its walk — but "safe" is not "derived".

## The remedy, and the one that is worse

**TAKEN AS PROPOSED**: a marker the enumeration can read. The file already
ratifies things in parentheses (`(v0.1.4, T-016)`), so a bullet could
open `- POISON DRILL (DISCIPLINE; ratified at T-054…)` and the
enumeration becomes exact with no list anywhere.

**REJECTED IN ADVANCE**: a LIST of discipline bullets, in CONVENTIONS or
in the tool. That is the defect this whole card exists to remove — a
second copy of a set goes stale the day the set changes, and this file
has three stale signposts inside ONE bullet already, every one caught by
the lane that falsified it and NOT ONE by a gate.

**AND THE COUNT MUST NOT BE PINNED EITHER WAY.** A tally of disciplines
is a line number by another name. What the marker buys is a derivation
that cannot silently widen; it buys no figure.

Fence: `[docs/CONVENTIONS.md]`. Cheap, and it makes one row of every
future brief exact instead of generous.
