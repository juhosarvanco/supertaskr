## What was measured

Every seat is ordered to read five documents first: 242,673 bytes, about 61K tokens, before any work; the superpowers bootstrap is 3,322 characters. The context pack already carries a lane the bullets its fence implicates (T-254), so the five-file order is paid by every seat for what the pack delivers to the one that needs it.

## Acceptance criteria

- WHEN CLAUDE.md and AGENTS.md (and the kit's adapters) are read THE order SHALL be docs/STATE.md then a one-line description index of ROADMAP, ARCHITECTURE, CONVENTIONS and CAPABILITIES — one line per document naming the question it answers and when to open it — and nothing else standing; a body SHALL measure the standing read under 10,000 tokens at the tip.
- WHEN a governing document's opener changes THE index SHALL be regenerated by the same command that regenerates the census, and the docs gate SHALL red when the committed index is stale — seen red on a planted stale line.
- WHEN a seat needs a rule the pack did not hand it THE rule stated in the index's line SHALL be to ask (the ask file) or to open the document by the bullet, never to guess; the T-138 instance is the case named.
- The five documents SHALL keep their contract and budgets (ADR-019, ADR-023); this card moves the ORDER of reading, not a byte of their content.
