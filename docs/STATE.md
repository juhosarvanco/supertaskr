## Standing hazards — the section that saves the hour

- **CALLBACK TRANSACTIONS SERIALIZE RECORD UPDATES; PARALLEL WRITERS
  REMAIN UNQUALIFIED.** The bounded lock holds read/modify/write;
  contention and unknown callbacks remain recorded. Tools and owned jobs
  must cease before collection; never synthesize a missing callback.
  Bash/apply_patch are the measured boundary, not OS/read isolation.
  Prefix writer commands with the exact resource, then enter the package.
  Use frozen detached preparation, never a manual manifest; packet-only
  has neither repository ref nor reservation.
- **CONTINUE THEN EXACT REBIND BEFORE OBSERVE/SEND.** Continuation clears
  execution; observing a pending ask first can leave an unbound blocked
  attempt. Preserve the hold and resource; do not hand-edit authority.

- **REVIEW PACKETS DO NOT DISPLAY RAW AUTHORITY CARD TEXT**: it can carry
  executor notes. Validate raw bytes privately and supply metadata only;

  keeper scans comments and workflow files.
