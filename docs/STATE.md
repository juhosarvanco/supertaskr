## Standing hazards — the section that saves the hour

  REMAIN UNQUALIFIED.** Atomic replacement alone is insufficient: the
  landed bounded transaction lock holds read/modify/write and preserves
  contention/unknown callbacks. Root tools and native worker processes
  must finish before collection; a missing callback is never synthesized.
  Bash/apply_patch are the measured tool boundary, not OS/read isolation.
  Prefix each writer command with its exact resource and explicitly enter
  its package. Use the supported frozen detached preparation, not a
  hand-written manifest; packet-only has no repository ref or reservation.

  executor notes. Validate raw bytes privately and supply metadata only;
