# Naming — resolved

**Final name: nputer** — computer minus "co"; house-style sibling of
Omputer (computer minus "c"). Decided 2026-08-14 (rooms/naming.md).
Availability at decision time: npm FREE (critical for `npx nputer`),
PyPI free, GitHub ~1 trivial hit. Still to sweep: domains
(.dev/.fi/.com), trademark in key markets.

Historical record of the candidate rounds below ("nputer" appears where
the former working name alku was globally renamed).

## Constraints
Typeable as a command (lowercase, ~4–7 letters, no diacritics),
pronounceable everywhere, unclaimed in dev tooling, and TRUE about the
product. Before committing: npm / PyPI / crates / GitHub org / domains
(.dev/.fi/.com) / trademark sweep in key markets.

## The identity fork (the real decision)
The name should declare what the product IS:
- **the discipline** (vibe brought into form)
- **the plan** (the plot held coherent)
- **the crew** (many hands, one build)
- **the orchestration** (voices under rules)

## Round 1 — Finnish
- **Vire** — tune/tone/form; the Finnish cousin of "vibe" — "vibe,
  disciplined" in one word. Front-runner of the round.
- **Juoni** — the plot/storyline (+ sly "scheme"); names the story map.
- **Talkoot** — communal barn-raising; the multi-agent story itself.
- **Alusta** — platform AND "from the beginning"; elegant pun, common
  word (collision risk).
- **Runko** — backbone/frame/hull; the doc skeleton.
- **Kudos** — weave/fabric in Finnish, praise in English; squatted.
- Shelf: Kehto (cradle), Latu (ski track), Sauma (seam/chance).

## Round 2 — other languages
- **Fuga** — fugue: independent voices entering one at a time,
  developing one theme under strict rules — a DESCRIPTION of the
  product, not a metaphor. Cross-language front-runner; check the
  European cloud-company collision.
- **Trama** — Italian/Spanish: plot of a story AND weft of a fabric;
  both governing metaphors in one existing word.
- **Kata** — practiced form; "code kata" recognition built in.
- **Takt** — the beat; lean manufacturing's cadence term.
- **Sutra** — thread → terse binding rule-texts.
- **Fundi** — Swahili: the master builder you call.
- **Kumu** — Japanese "assemble/team up" + Hawaiian "teacher/source".
- **Norn** — Norse fate-weavers; darkest, coolest, least
  self-explanatory.

## Round 3 — punchy / house style (Omputer, Hey Clicky, Slapmac)
- **Rchitect** — architect minus the A; the Omputer sibling; names the
  main character. Alias `rch` in the terminal.
- **Muster** — assemble the troops; `muster init / next / status` is
  CLI poetry. Round front-runner for the terminal.
- **Slapdash** — the ironic anti-name: the tool that cures slapdash.
  The tagline writes itself; joke-risk accepted knowingly.
- **Plotto** — plot + o; toy-shaped; 1928 plot-machine heritage story
  for free.
- **Drover** — herds the mob across long distances.
- **Ringmaster** — the circus you run; most visual, longest.
- **Wrango** — wrangle + o (plain "wrangler" is Cloudflare's — dead).
- **Hey Archie** — the architect personified; best kept as the
  CHARACTER inside the app regardless of the app's name.
